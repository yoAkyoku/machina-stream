# Security policy

Machina Stream is a local portfolio/demo project. It uses synthetic telemetry, has no authentication or tenant isolation in v1, and must not be connected to real PLCs or exposed as a production control system.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's repository security advisory feature when it is enabled. If private reporting is unavailable, contact the maintainer through their GitHub profile and do not post exploit details in a public issue.

## Supported versions

Only the current default branch is supported until the project publishes a release.
